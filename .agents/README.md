# Configuración de Custom Agents del Proyecto (.agents)

Este directorio alberga las personalizaciones, habilidades y agentes de inteligencia artificial para el proyecto **APP PADEL** en Google Antigravity.

## Estructura del Directorio

- **`skills/`**: Habilidades empaquetadas con guías procedimentales, scripts y referencias.
  - [`custom-agent-builder`](./skills/custom-agent-builder/SKILL.md): Guía completa, arquitectura y especificaciones para crear y desplegar subagentes personalizados (basada en el artículo oficial *Introducing Custom Agents* de Google Antigravity).
- **`agents/`**: Manifiestos YAML de los agentes configurados para este espacio de trabajo.
- **`rules/`**: Reglas y directrices de codificación que aplican a todos los agentes.

## Habilidad Disponible: `custom-agent-builder`
Para utilizar o generar nuevos agentes, consulta la documentación en [skills/custom-agent-builder/SKILL.md](./skills/custom-agent-builder/SKILL.md).
